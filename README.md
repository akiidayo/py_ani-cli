# py_ani-cli
i have made an py script to run anime with ani-cli for no click auto-next using py 

requirement _______

1ani-cli
2mpv
3pythone3
4linux
5zshrc/bshrc config
6git and base devel 

steps --------
1. add py in main file (~) (base directory)

1.1

2  run javac ani.py 

3  run python3 ani.py "anime name" ep_no
for test 

4  open .zshrc

5  add alias ani='python3 ani.py' wereever you want

6 now you can just run ani "ani_name" ep_no (which ep to start)

7 or you can run 
ani "ani_name" (resume from last seen ep)
